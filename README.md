# Sales Performance Dashboard
## Project Overview

This project analyzes retail sales data to uncover trends in revenue, profit, product performance, and regional sales. The analysis includes data cleaning, exploratory data analysis (EDA), and the development of an interactive Power BI dashboard to support business decision-making.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI
- Git & GitHub

## Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization

- KPI Development
